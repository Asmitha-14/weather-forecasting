# Weather Forecasting

## AI-Based Short Term Weather Forecasting using Time Series Deep Learning

This project uses historical weather data and deep learning techniques to predict short-term weather conditions.

## Technologies Used

- Python
- TensorFlow / Keras
- Pandas
- NumPy
- Scikit-learn
- Time Series Analysis
- Deep Learning

## Project Features

- Weather data preprocessing
- Time series based forecasting
- Deep learning model training
- Model comparison
- Weather prediction using trained model

## Project Files

- `main.py` - Main prediction program
- `train_model.py` - Model training
- `model_comparison.py` - Comparison of models
- `new_weather.csv` - Weather dataset
- `weather_model.keras` - Trained deep learning model
- `scalerX.save` - Input data scaler
- `scalerY.save` - Output data scaler

## How It Works

Historical weather data is preprocessed and used to train a deep learning model. The trained model is then used to predict short-term weather conditions.
